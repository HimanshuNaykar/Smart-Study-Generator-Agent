# Smart Learning Assistant using Generative AI

> An AI-based educational assistant that converts study resources into personalized learning content using LangFlow, IBM watsonx.ai, IBM Granite Models, and RAG Technology.

---

## About The Project

**Smart Learning Assistant** is an intelligent AI-powered education platform designed to support students and educators in managing learning materials efficiently.

The system uses Generative AI and Retrieval-Augmented Generation (RAG) to analyze uploaded academic documents and generate meaningful learning resources.

Users can upload:

* Lecture Notes
* PDF Documents
* Study Materials
* Reference Books
* Research Documents

The AI assistant converts these resources into:

* Structured Notes
* Quick Revision Material
* Question Bank
* Learning Cards
* Exam Preparation Content
* Personalized Study Guidance

---

## Working Methodology

1. Student uploads academic resources.
2. Documents are processed and divided into meaningful sections.
3. AI creates document embeddings.
4. Knowledge is stored in a vector database.
5. RAG retrieves required information.
6. IBM Granite generates accurate responses.
7. Learning content is created according to student needs.

Run Application

```bash

```
